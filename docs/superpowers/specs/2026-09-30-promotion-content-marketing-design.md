# 推广获客设计：内容营销长线（方案 B）

日期：2026-09-30
状态：已与用户确认

## 背景与目标

项目 llm-translate-minimal 已推送到 GitHub（https://github.com/shen1997-hub/llm-translate-minimal），当前 README 为纯中文纯文字、无演示素材、无 GitHub topics，未上架任何扩展商店（用户明确暂不考虑上架，只做 GitHub 分发）。

目标：通过内容营销获取更多流量与 GitHub star。
建议北极星指标：90 天内 500 star。过程指标：单帖 V2EX 回复 ≥ 20；HN Show 进首页前 30 即算成功；每帖记录阅读量/点击/star 增量。

## 核心决策

- **打法**：内容营销长线（方案 B）。用户拒绝了「仓库精修 + 素材驱动分阶段投放」（方案 A）与「极简快攻」（方案 C），但认可方案 B 必须包含**最小门面**（README 演示 GIF + topics + 英文简介）作为文章流量的着陆页。
- **主战场**：中文与国际并重、分阶段。中文社区快攻先行，英文素材随后。
- **可用渠道**（用户确认有账号且愿意发帖）：V2EX / 掘金 / 少数派、Reddit / HN / X、B站 / 视频号。

## 内容定位

一句话主张：**「不用订阅的 AI 网页翻译——带上你自己的 key，或者用免费模型」**

三大支撑点：
1. **零订阅**：自带 OpenAI 兼容 API（DeepSeek/GLM/Moonshot/Ollama），硅基流动有免费翻译模型，真正的零成本
2. **极简**：整页双语对照 + 划词浮窗两个核心功能，无全家桶
3. **有记忆点**：划词翻译时有猫咪助手动态响应——传播素材的视觉钩子

对标：沉浸式翻译（订阅制、功能重）。不贬低，强调「轻量、免费、自己的 key」差异化。

## 选题库（12 个，前 6 个为第一批）

2. 《DeepSeek API 翻译整个网页：从申请 key 到双语对照只要 5 分钟》——蹭模型关键词搜索流量
3. 《本地 Ollama 也能网页翻译：完全离线的双语阅读方案》——隐私卖点，适合掘金 / Reddit r/LocalLLaMA

### 支柱二：对比/替代类（少数派痛点文）
4. 《不想订阅沉浸式翻译？这个开源插件让你用自己的 API key》——对标文，争议性带来讨论量
5. 《2026 年网页翻译方案横评：订阅制 vs 自带 key vs 免费模型》——横评文，天然带搜索流量

### 支柱三：开源故事类（V2EX / HN / Reddit）

### 支柱四：视频类（B站/视频号）

### 支柱五：技巧类（长尾补充）

## 节奏

每周 1 篇文章 + 每两周 1 条视频，前 6 篇约一个半月发完。同一篇文章按渠道改写：掘金重教程步骤、少数派重效率叙事、V2EX 重故事和开源。

## 发布流程（每篇重复）

成稿 → 按渠道改写 → 用户人工发布 → 48h 内盯评论回复 → 数据记录（阅读量/点击/star 增量）→ 迭代下一选题。
每个帖子唯一目标动作：点进 GitHub 仓库。

## 风险与注意

- Reddit 对 self-promotion 严格，新号直发易被封，需先参与社区互动
- 对比文（选题 4、5）注意措辞，聚焦差异化而非贬低竞品，避免引战
- star 增量高度依赖首帖质量，选题 6 的标题和 GIF 是最高优先级素材
